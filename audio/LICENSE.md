## Salvage package sequence

The four `salvage-*.m4a` cues are edited composites of Creative Commons CC0
recordings. They replace the package reveal's former synthesized tones/noise.

- **“Doomsday Laser Cannon Sound Effect” by TAD** supplies the pressure rise
  and primary release transient:
  https://opengameart.org/content/doomsday-laser-cannon-sound-effect
- **“Platformer Sounds: Terminal, Interaction, Door, Shots, Bang and
  Footsteps” by yd** supplies `cogs.ogg`, `door_open.ogg`, `landing.ogg`,
  `explode.ogg`, and `boxopen.ogg`:
  https://opengameart.org/content/platformer-sounds-terminal-interaction-door-shots-bang-and-footsteps
- `ship-rattle.wav` by BMacZero, already documented above, supplies the short
  metal-debris layer in the release.

All three sources are CC0 1.0. The edits are trims, fades, EQ, pitch changes,
level normalization, and layering; no additional third-party sample is used.

Verified upstream package hashes (downloaded August 27, 2026):

- `doomsday_laser_cannon_long.wav` SHA-256: `a8bec22b2ab2af66cb5b49d87f90c6348f5851a9902bf9ebfe2ac727f902d0a4`
- `yd-Sounds.zip` SHA-256: `d88921e4a4c3d02acc09d605aaa02ab89fa1d9f6e28ed56d79d37e04e15241b5`

| Shipped cue | Source edit |
| --- | --- |
| `salvage-arrive.m4a` | door actuator + metal landing impact |
| `salvage-charge.m4a` | pre-impact laser-cannon pressure rise + mechanical cogs |
| `salvage-release.m4a` | cannon release + explosion + package-open hit + metal rattle |
| `salvage-reward.m4a` | pitched and filtered package-open tail |

The four `ui-*.m4a` ecosystem-navigation cues use the same CC0 `yd-Sounds`
source collection above so the shell package and menus share one mechanical
language. `ui-select` trims and pitches a terminal pulse; `ui-navigate` trims
the door actuator; `ui-back` reverses and filters that actuator; `ui-confirm`
uses a short, quieter package-open hit.
